# Local datasets

This directory holds downloaded and prepared datasets. Its contents are generated by `src/prepare_task.py` or the older experiment scripts and are excluded from Git.

Reusable task data is written to `data/tasks/<task_name>/` as train, validation, and test JSONL files with a manifest and task snapshot. Start from the repository root and run, for example:

```bash
.venv/bin/python src/prepare_task.py --task tasks/emotion_classification.json
```

Check each source dataset's license before sharing its records.
